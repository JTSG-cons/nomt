# NOMT — Investor Teaser

A single-page, trilingual (**Монгол / 中文 / English**) investor teaser for **NOMT (Номт)**, a 15-floor serviced-residential complex in Ulaanbaatar developed by **JTSG LLC**.

- Single static `index.html` — Tailwind via CDN, no build step. Images in `assets/`.
- **Five functions, one vertical asset**: for-sale residences, serviced apartments, office, commercial podium and automated parking — explored floor by floor.
- Deep-emerald + gold palette, high-contrast serif display, fully responsive, accessible (keyboard, reduced-motion), trilingual.

## View locally
Open `index.html` in a browser, or serve the folder over HTTP.

## Hosting
Static — works on GitHub Pages or any static host. Upload `index.html` and the `assets/` folder.
